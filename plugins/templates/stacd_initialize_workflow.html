How it works:

  1. Upload your 3 YAML configuration files
  2. Click "Initialize Workflow"
  3. The system will:
    • Save YAMLs to the config directory
    • Initialize the database with algorithms, datasets, and DAG structure
    • Generate the DAG Python script from your YAML specification
    • Deploy the DAG to Airflow so it appears in the DAGs dashboard
  4. Navigate to DAGs in the top menu to see and trigger your workflow!
Note: If a DAG with the same ID already exists in the database, initialization will be skipped. Use STACD → Update DAG to modify an existing workflow.
